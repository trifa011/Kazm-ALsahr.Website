# 🎵 Kazem Al Saher Website

A responsive fan-made website dedicated to **Kazem Al Saher**, created as a web development project to practice and demonstrate front-end development skills.

The website presents information about his journey, songs, gallery, and includes interactive pages such as a booking form and contact section.

## 🌐 Project Overview

This project was created to practice building a complete multi-page website using **HTML, CSS, and JavaScript**.

### Pages Included

* 🏠 **Home** – Introduction and main navigation
* 👤 **About** – Information about Kazem Al Saher
* 🎤 **Journey** – His artistic journey and career
* 🎵 **Songs** – Selected songs and audio/video content
* 🎟️ **Booking** – Sample booking form with different packages
* 🖼️ **Gallery** – Collection of images
* 📩 **Contact** – Contact form and information

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design
* YouTube Integration

## ✨ Features

* Multi-page website structure
* Responsive design
* Navigation between pages
* Interactive booking form
* Form validation using JavaScript
* Dark mode
* Embedded YouTube content
* Image gallery
* Clean and organized layout

This is a **practice and portfolio project**, created to improve my skills in front-end web development and learn how different website pages and interactive features work together.
